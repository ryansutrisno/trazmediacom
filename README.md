# Trazmediacom

Website resmi Trazmedia — software house Indonesia berbasis di Sleman, Yogyakarta.

## Tech Stack

- **Astro 5** — Static + server-rendered pages
- **Tailwind CSS v4** — Utility-first styling
- **React 19 + TanStack Query** — Interactive islands
- **TypeScript** — Type-safe development
- **Vercel** — Deployment & hosting

## Getting Started

```bash
npm install
npm run dev
```

## Release

Push ke branch `main` → semantic-release auto release & changelog.
